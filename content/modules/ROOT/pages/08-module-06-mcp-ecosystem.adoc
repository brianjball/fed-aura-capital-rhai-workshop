Tools that let agents interact with other systems.

Lenora can answer questions about mortgages, but she cannot take action. Ask a regular chatbot "I make $100K, have $500 monthly debt, and $20K down payment. How much house can I afford?" and you get a range - "$390K-$410K" - hedged with assumptions and disclaimers. An agentic chatbot with MCP tool access calls `affordability_calc` and returns "$488,000" precisely, calculated from your actual numbers. The difference is not smarter prompting. The difference is tool access.

=== Key Takeaways

* The difference between a regular chatbot and an agentic chatbot is not smarter prompting - it is tool access managed through MCP
* MCPServerRegistration CRDs provide a Kubernetes-native way to register, manage, and govern tool access for AI agents
* The MCP gateway acts as a control plane for tool connectivity, providing a single entry point for all registered MCP servers
* Tool-backed responses eliminate guesswork and deliver precise, actionable answers calculated from real data
