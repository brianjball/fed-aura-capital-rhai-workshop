Monitoring and measuring every AI decision.

Fed Aura Capital is running agentic AI for risk assessments. Regulators require full traceability. The CTO needs to know if the AI is making correct recommendations, what tools it called, how long each step took, and whether prompt changes cause regressions. Without observability, the system is a black box. With MLflow tracing and EvalHub, every agent decision is recorded, measurable, and auditable.

== Learning Objectives

By the end of this module, you will be able to:

* Navigate MLflow Experiments and explore agent traces
* Deep-dive into a multi-step agent trace to understand the full decision path
* Verify that predictive model integration (AutoML from Module 4) appears in agent traces
* Run an automated evaluation pipeline and review results
* Use EvalHub for centralized evaluation management and cross-version comparison

=== Key Takeaways

* MLflow tracing provides full observability into every agent decision - what tools were called, what inputs they received, what outputs they produced, and how long each step took
* Predictive model integration is verifiable through traces - you can confirm that the AutoML model from Module 4 is actively used in agent decision-making
* Automated evaluation pipelines replace manual spot-checking with repeatable, quantifiable quality measurement
* EvalHub enables cross-version comparison so prompt changes can be validated before deployment, catching regressions early
* Structured, timestamped traces satisfy regulatory requirements for traceability and auditability
